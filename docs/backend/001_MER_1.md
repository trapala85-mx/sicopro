# MER 1. Project - Moduel - ProjectType✅

---

## Resumen final del diseño

**`Module`**
- `id`: uuid, PK
- `name`: string, **unique**
- `parent`: FK a sí mismo, nullable
- `order`: int
- `is_active`: bool, default `True`

**`ProjectType`**
- `id`: uuid, PK
- `name`: string, unique

**`ProjectTypeModule`** *(pivote)*
- `id`: uuid, PK
- `project_type`: FK a `ProjectType`
- `module`: FK a `Module`
- `is_active`: bool, default `True`

**`Project`**
- `id`: uuid, PK
- `name`: string, unique
- `project_type`: FK a `ProjectType`
- `is_active`: bool, default `True`

**`ProjectModule`** *(pivote)*
- `id`: uuid, PK
- `project`: FK a `Project`
- `module`: FK a `Module`
- `is_active`: bool, default `True`

---

## Requerimientos que este MER cumple

**Module**
- Crear un módulo con `name` único, `parent` opcional, `order` global, `is_active` default `True`
- Editar un módulo completo o parcial
- Activar / desactivar un módulo en cascada hacia sus submódulos
- Un módulo puede tener submódulos mediante la autoreferencia `parent`

**ProjectType**
- Crear un tipo de proyecto
- Al crearlo, `Home` se agrega automáticamente a `ProjectTypeModule`
- Agregar, editar, activar/desactivar o eliminar módulos dentro de un tipo de proyecto via `ProjectTypeModule`

**Project**
- Crear un proyecto con `name` único, `project_type` obligatorio, `is_active` default `True`
- Al crearlo, se copian automáticamente los módulos de su `ProjectType` a `ProjectModule`
- Editar un proyecto completo o parcial
- Activar / desactivar un proyecto
- Eliminar un proyecto
- Desactivar módulos específicos de un proyecto via `ProjectModule` sin afectar el `ProjectType`

---

## Reglas de negocio

**Módulo `Home`**
- Debe existir en el sistema antes de crear cualquier `ProjectType`
- Si no existe al intentar crear un `ProjectType` → error explícito
- Siempre `order = 0`
- Nunca se puede desactivar ni eliminar — en ninguna tabla

**Module**
- `name` es único globalmente
- Desactivar un módulo desactiva en cascada todos sus submódulos
- La cascada recorre la autoreferencia `parent` hacia abajo

**ProjectType**
- Al crear un `ProjectType`, `Home` se agrega siempre y primero a `ProjectTypeModule`
- Un cambio en un `Module` se propaga a todos los `ProjectTypeModule` relacionados

**Project**
- `project_type` es obligatorio al crear un proyecto
- Al crear un `Project`, se copian todos los módulos activos de su `ProjectType` a `ProjectModule`
- Un cambio en `ProjectTypeModule` se propaga a los `ProjectModule` de todos los proyectos de ese tipo
- Desactivar un módulo en `ProjectModule` no afecta `ProjectTypeModule`
